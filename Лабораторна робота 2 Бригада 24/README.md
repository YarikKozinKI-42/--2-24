KitchenNotes – Лабораторна робота №2

Тема: Створення структури веб-проєкту  

Опис проєкту
KitchenNotes – кулінарний сайт з рецептами домашніх страв.  
Сайт розроблено на чистому HTML та CSS відповідно до вимог Лабораторної роботи №2.

Структура проєкту

KitchenNotes
│
├── index.html          – Головна сторінка
├── catalog.html        – Каталог рецептів
├── recipe-item.html    – Сторінка рецепта (Карбонара)
├── about.html          – Про нас
├── contact.html        – Контакти
│
├── css
│   └── style.css       – Стилі сайту
│
├── js
│   └── (порожня папка)
│
│
└── README.md           – Короткий опис проекту

Список створених сторінок

1. index.html – Головна: герой-банер, сітка популярних рецептів, список переваг
2. catalog.html – Каталог: рецепти розбиті по категоріях (Паста, Супи, Салати, Десерти)
3. recipe-item.html – Рецепт: покрокова інструкція + список інгредієнтів
4. about.html – Про нас: фото, текст, список цінностей, нумерований список досягнень
5. contact.html – Контакти: адреса, телефон, форма з полями input/textarea/select

Виконані вимоги лабораторної роботи

1. Структура проєкту
Папка css – таблиці стилів
Папка js – скрипти
Логічні назви файлів

2. HTML-сторінки (5 штук)
На кожній сторінці: <header>, <nav>, <main>, <footer>
Меню навігації з посиланнями на всі сторінки

3. HTML-теги та атрибути
Заголовки <h1>, <h2>, <h3> – правильна ієрархія
Абзаци <p>
Ненумерований список <ul> (навігація, інгредієнти, цінності)
Нумерований список <ol> (кроки рецепта, досягнення)
Посилання <a href="..."> – внутрішня навігація, email, tel
Зображення <img> з атрибутом alt – на всіх сторінках
Форма <form> з <input>, <textarea>, <select>, <label>

4. Семантичні теги
<article>, <section>, <aside>, <address>, <em>, <strong>

5. Валідність та оптимізація
Атрибути width та height на зображеннях
Перевірка W3C Validator
